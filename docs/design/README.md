# Design

**Brand:** **Oh, right!** with the tagline *your little memory*. Wordmark: “oh, **right!**” in Nunito Black, slightly tilted, *right!* in orange `#F57908`. Icon: “oh,” on orange (`brand/`). Voice: the app is your memory talking, warm and never pushy.

**Target design: [oh-app.html](oh-app.html)** (clickable, dummy data, phone-first; on your own and in shared spaces for couples and groups). Live: https://bazom.github.io/IdeaMemory/design/oh-app.html. This is what we build towards; the product principles and main flow behind it are in the [roadmap](../roadmap.md).

- `oh-app.html`: the target design, full screen on phones. Use this link to show the design.
- `oh-app-with-our-memory.html`: the version before “one memory, spaces decide”. It still had *Our memory* per space, moving a memory into a space and the pick-one-of-three date night.
- `oh-full-experience.html` (and `.fragment.html`): the owner’s original reference design.
- `brand/`: app icon (512 px), home-screen icon (180 px) and favicon.

**Backups:** before a design change, the current page is saved as `oh-app-with-<what it had that the new one won’t>.html`. Older backups and drafts are in the git history.

**Demo spaces in the prototype:** *Just me*; *You & Lena* (two of you, date night on, taking turns, a jar of matches); *You & Mira* (two of you, date night offered); *The regulars* (group with a weekly fixed activity, falling on today); *Lisbon crew* (group with an open weekly slot tomorrow, a trip plan and news).
